# BRFSS ML Project Vault

Open this folder in [Obsidian](https://obsidian.md) (File → Open folder as vault).

## Structure
- **10 Project** — rules, roadmap, live rubric checklist, deadlines, AI assistance log
- **20 Experiments** — one note per experiment (EXP-xxx), from the template
- **30 Decisions** — ADRs; methodology changes require one before implementation
- **40 Data Notes** — column triage, leakage watchlist, codebook highlights
- **50 Daily Logs** — one note per working day
- **90 Attachments** — figures embedded in notes

## Conventions
- Wikilinks between notes; tags: `#exp` `#adr` `#daily` `#data`
- Every experiment note links its ADRs, figures and `results/experiments_log.csv` row
- This vault is committed to git by the **vault-scribe only** — workers never edit it
- Binding project rules live in `AGENTS.md` at repo root (this vault mirrors, not replaces, them)
